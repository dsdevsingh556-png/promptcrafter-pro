# Deployment Checklist

- Run `npm test`.
- Run `npm run build`.
- Confirm the `dist` directory contains the application.
- Import the repository into Vercel.
- Compile coding, research, data, writing, and agent requests.
- Save a local project version and export it.
- Test 360, 390, 412, tablet, and desktop widths.
- Test keyboard navigation.
- Load once, disable the network, and compile again.
- Inspect network traffic before adding analytics or making privacy claims.
